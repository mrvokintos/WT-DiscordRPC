# WT Discord RPC

[English](README.md) | **Русский**

Discord Rich Presence для War Thunder на Linux и Windows. Показывает, где вы сейчас: в ангаре, на загрузке или в бою. В бою видно технику и её картинку, а по желанию ещё скорость и высоту или скорость и экипаж.

Проект вдохновлён [WarThunderDiscordRPC](https://github.com/ledxdeliveryflopp/WarThunderDiscordRPC) от ledxdeliveryflopp. Это отдельная реализация на Rust, общего кода с оригиналом нет.

Программа только читает локальный API игры (`localhost:8111`, его же использует карта в браузере). Файлы и память игры она не трогает.

## Установка

Скачайте архив для своей системы на странице [Releases](https://github.com/mrvokintos/WT-DiscordRPC/releases), распакуйте его и запустите `wt-discord-rpc`. В трее появится значок. Чтобы программа запускалась сама при входе в систему, включите пункт «Запускать вместе с системой».

На Linux трей работает через StatusNotifierItem. В KDE он поддерживается сразу, в GNOME нужно расширение AppIndicator. Если трея нет, программа работает без него. Флаг `--no-tray` отключает трей принудительно.

Discord находится автоматически, как бы он ни был установлен: обычной программой, через Flatpak (в том числе Vesktop) или Snap.

## Настройки

Основные настройки есть в меню трея. Все они хранятся в `config.toml`, папку с ним открывает пункт «Открыть папку с настройками»: на Linux это `~/.config/wt-discord-rpc/`, на Windows — `%APPDATA%\WT Discord RPC\`. Если `config.toml` лежит рядом с исполняемым файлом, программа берёт настройки оттуда (портативный режим).

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `client_id` | приложение проекта | id приложения Discord (см. ниже) |
| `lang` | `auto` | `auto`, `ru` или `en`: язык интерфейса и названий техники |
| `logo` | `main_white` | `main_white`, `main_red` или `main_diamond` (иконка игры) |
| `show_indicators` | `true` | скорость, высота и экипаж во второй строке |
| `air_speed` | `IAS` | `IAS` или `TAS` |
| `altitude` | `RADIO` | `RADIO` (если радиовысоты нет, показывается абсолютная) или `ABSOLUTE` |
| `custom_images` | `true` | показывать картинку из приложения Discord, если она загружена для этой техники |
| `show_kills` | `false` | сколько ты уничтожил в текущем бою, по киллфиду (нужен `nickname`) |
| `nickname` | пусто | ник в игре без тега полка, с учётом регистра |
| `show_nation` | `false` | нация и класс техники в подписи маленькой картинки; с флагом (картинка `flag_<нация>` из приложения, если загружена, иначе из `assets/flags`) |
| `battle_timer` | `false` | в бою таймер считает с начала боя, в ангаре — с запуска игры |
| `wiki_button` | `false` | кнопка «Машина на вики», когда ты на технике; Discord показывает кнопки другим, но не тебе |
| `repo_button` | `false` | кнопка «WT Discord RPC» со ссылкой на этот проект |
| `api_url` | `http://localhost:8111` | адрес API игры (переменная окружения `WT_API_URL` имеет приоритет) |
| `names_url` | `db-latest` из WT-Vehicles-Parser | откуда обновлять названия; пустое значение отключает обновление |
| `check_updates` | `true` | проверять новую версию при запуске |

## Названия техники

Названия берутся из [WT Vehicles Parser](https://github.com/mrvokintos/WT-Vehicles-Parser). Он читает их из локализации самой игры (`units.csv`), поэтому они совпадают с деревом исследований. Копия встроена в программу. После патча игры новая версия скачивается автоматически, а пункт трея «Обновить названия техники» скачивает её сразу.

## Своё приложение Discord

Название в Discord («Играет в War Thunder») и логотипы задаются приложением Discord. Чтобы использовать своё приложение:

1. Создайте приложение с названием «War Thunder» на <https://discord.com/developers/applications>.
2. По желанию в разделе Rich Presence → Art Assets загрузите свои логотипы под именами `main_white`, `main_red` и `main_diamond` (иначе берутся логотипы из `assets/logo`). Можно также загрузить картинки техники, назвав их по id машины (например, `us_m1a1_aim_abrams`): при включённом `custom_images` они заменят картинку из энциклопедии.
3. Укажите Application ID в `client_id`.

Флаги работают сразу (`assets/flags` в этом репозитории). Чтобы использовать свои, загрузите картинки под именами `flag_usa`, `flag_germany`, `flag_ussr`, `flag_britain`, `flag_japan`, `flag_china`, `flag_italy`, `flag_france`, `flag_sweden`, `flag_israel`. Флаги самой игры есть в датамайне: `atlases.vromfs.bin_u/gameuiskin/country_<нация>_round.svg`.
